経、世万材紙居内欲籠材其処。

## 二、造材包向世万

二序、造新籠内`.minecraft`含`resourcepacks`籠、取`assets`籠元其拡録然籠、据其於新籠。

在等処、造`pack.mcmeta`紙。之為定材包則然紙。
経、書左言内`pack.mcmeta`。

```
{
    "pack": {
        "pack_format": <span class="phun">向世万</span>,
        "name": "<span class="phun">材包名</span>",
        "description": "<span class="phun">論事向材包</span>"
    },
    "language": {
        "<span class="phun">事言録</span>":{
            "name": "<span class="phun">事言名</span>",
            "region": "<span class="phun">使其事言処</span>",
            "bidirectional": false
        }
    }
}
```

要書正事在`"pack_format"`。求記[之知帳](https://minecraftjapan.miraheze.org/wiki/%E3%83%AA%E3%82%BD%E3%83%BC%E3%82%B9%E3%83%91%E3%83%83%E3%82%AF/%E4%BD%9C%E3%82%8A%E6%96%B9#%E3%83%AB%E3%83%BC%E3%83%88%E3%83%95%E3%82%A9%E3%83%AB%E3%83%80)。

在`"language"`、書事言名使定字。其為態`ex_ex`。

* 制書之使**定大字**。求使**定小字**。在`"name"`来`"region"`、能書万字。

左言為我定紙向之記。

```
{
    "pack": {
        "pack_format": 6,
        "name": "test",
        "description": "Resourcepack for example"
    },
    "language": {
        "ex_ex":{
            "name": "example lang",
            "region": "my home",
            "bidirectional": false
        }
    }
}
```

求動世万後做之法。行「材包」、汝目左態画模其為正働！

## 四、使汝字集

造言民不豊心之可。由為**我不去訓何法使字集事**。内之記片訓其。

要持`.ttf`字集居向做之。我不去使異字集、故不知使其事。使「能山」字内之記。

<CaptionedImage src="/cuangnem/20231222/aldas.png" width={300} title="「能山」字"/>

経据字集紙於`assets`含`minecraft`含`font`籠。

* 紙名制等為**定大字**在之。要使**定小字**。

在等処、`default.json`居。定字集内之。之態門書`"providers"`。

```
"providers": [
    {
        "type": "ttf",
        "file": "minecraft:<span class="phun">(字集紙名)</span>.ttf",
        "shift": [0, 0],
        "size": 10.0,
        "oversample": 4.0
    },
    ...<span class="phun">(多事)</span>
]
```

向動字処、使`"shift"`。`"size"`定字大事、`"oversample"`定字真。

経、回動世万。目汝字集模其為正働！
汝去做！！
